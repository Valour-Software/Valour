Raw application assets

Files in this directory and its child directories are packaged by the MauiAsset
entry in Valour.Client.Maui.csproj:

    <MauiAsset Include="Resources\Raw\**" LogicalName="%(RecursiveDir)%(Filename)%(Extension)" />

Read a packaged file by its logical name with FileSystem.OpenAppPackageFileAsync.
For a file in a child directory, include that relative directory in the name.

    async Task<string> ReadAssetAsync()
    {
        using var stream = await FileSystem.OpenAppPackageFileAsync("AboutAssets.txt");
        using var reader = new StreamReader(stream);
        return await reader.ReadToEndAsync();
    }
